# Battlefield baseline

The optional public unit/side weights are downloaded from
[Pbatch/ClashRoyaleBuildABot](https://github.com/Pbatch/ClashRoyaleBuildABot/tree/f89ecbf309e698cb9fccdfb64a6ff2a930e6541e).
The adapter follows its unit class mapping, arena crop, letterbox and side-classifier
input contract. No upstream application code is executed during setup.
