# 浅色工作台 · 3.14.3 / UI1

主界面使用浅色背景、白色圆角卡片、蓝色主操作与细边框，以 Tk 和局部 Canvas 绘制实现，没有增加浏览器运行时、Qt 或额外 UI 依赖。

## 当前布局

3.14.2 按要求移除了“决策方式”“规则配置”两个选择器、离线校验卡片，以及整个工具箱入口和全部菜单选项。工具箱中的标定、训练数据、精确标注、无标注自学、自主学习状态、示范学习、双机同步和减少动态效果均不再作为主界面菜单展示。

3.14.3 进一步移除整个左侧栏，包括品牌、工作台和模型版本导航；自定义 ADB 移至右上角，与连接检测并列。主工作区使用全宽布局。顶部为设备连接、完成对局两张卡片；操作区保留运行状态、开始训练、安全停止和实际模型加载状态。模型详情点击模型状态即可打开。下方为实时画面与运行动态。

## 启动与运行

双击 `start_ui.bat`，先点击右上角“连接并检测”，再点击“开始训练”。它沿用现有用户级 Python 环境和依赖准备流程。

训练从配置文件及 `.royal-lab.json` 读取已保存的决策方式和规则配置。本次没有修改个人配置、默认引擎、模型兼容键或训练策略；内部离线入口验证继续执行。连接状态与日志更新不依赖已移除的卡片。已有独立脚本继续可用，例如首次标定运行 `calibrate.bat`、手动同步运行 `sync_data.bat`。

实时画面提供游戏画面、YOLO识别、同帧对照和推演快照。点击“放大”集中查看画面；“还原”恢复画面与日志布局。“安全停止”在放大后仍可见。

主界面保留 Ctrl+Enter 开始、Esc 停止和 F5 刷新。模型状态每 3 秒刷新，模型详情继续展示候选、验证结果及实际加载状态。

## 动画与轻量实现

按钮保留悬浮渐变、按压与柔和的背景聚焦反馈；移除按钮、下拉入口和选项上的蓝色焦点外框，窗口保留淡入，画面切换及放大/还原保留卡片过渡，运行状态灯保留呼吸效果。

画面模式下拉列表仍使用圆角浅色浮层、浅蓝选中背景和左侧标记。展开约 170 ms 淡入并轻微滑入，收起约 110 ms 淡出，箭头转动，选项悬浮渐变。支持鼠标点选、Enter/空格/F4/Alt+↓ 展开、↑↓/Home/End 导航、Enter 确认、Esc 取消和 Tab 切换。再次点击当前画面模式入口（例如“同帧对照”）即可收起，点击列表内当前选项也会收起。外部点击、失去焦点或主窗口移动/缩放时收起。

启动前设置 `CRBOT_REDUCED_MOTION=1` 可减少动态效果。动画只在对应交互时运行，销毁控件后取消回调。空闲消息检查为 100 ms；训练中的消息刷新保留 30 FPS 目标，界面显示实际数据帧率。

默认窗口为 1280×860，最小为 1040×700。高度不超过 760 时自动切换紧凑字号和间距，增大窗口后恢复。“轻量”指界面框架与绘制方式；已有识图、机器学习和 CUDA 运行库继续按原流程准备。本次更新源码界面，独立 EXE 未重新打包。
