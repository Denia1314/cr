# 浅色工作台 · 3.14.0 / UI1

本次重新设计主界面，使用 Windows 11 风格的浅色背景、白色圆角卡片、克制的蓝色强调与细边框。保留原有机器人功能，以 Tk 和局部 Canvas 绘制实现，没有增加浏览器运行时、Qt 或额外 UI 依赖。

## 启动和操作

双击项目中的 `start_ui.bat`。它沿用现有用户级 Python 环境和依赖准备流程，主窗口打开后，先点击右上角“连接并检测”，再选择“决策方式”和“规则配置”，点击“开始训练”。“安全停止”在放大实时画面后仍然可见。

左侧导航提供工作台、自定义 ADB、模型版本和工具箱。工具箱中的标定、数据目录、标注、自学、示范学习和双机同步接入原有功能；点击外部区域、切换窗口或按 Esc 可关闭浮层。主界面保留 Ctrl+Enter 开始、Esc 停止和 F5 刷新。

实时画面支持游戏画面、方格战场、同帧对照和推演快照。点击“放大”集中查看画面；点击“还原”或左侧“工作台”恢复画面与日志布局。模型版本面板继续显示实际加载情况、候选与验证结果。

## 动画与轻量实现

- 主窗口、模型详情和连接设置淡入；工具箱浮层淡入。
- 按钮、导航和工具箱选项在悬浮进入/离开时进行约 160 ms 的颜色渐变，按压时显示轻微反馈。
- 下拉选择框在悬浮与键盘聚焦时渐变边框；按钮支持 Tab 聚焦、空格及 Enter 操作。
- 画面切换、放大/还原和工作台恢复显示短暂的卡片边框过渡；运行状态灯保留呼吸效果。
- 工具箱“减少动态效果”或启动前设置 `CRBOT_REDUCED_MOTION=1` 可立即应用最终状态。

动画只在对应控件发生交互时短暂运行，控件销毁后取消回调。空闲消息检查为 100 ms；训练中的消息刷新沿用 30 FPS 目标。没有战场数据或视图隐藏时，网格检查器使用 100 ms 检查；有数据且可见时保留原有渲染节奏。实际数据帧率仍显示在界面上。

默认窗口为 1280×860，最小为 1040×700。窗口高度不超过 760 时自动切换紧凑字号和间距，为画面和运行动态留出空间；增大窗口后恢复正常间距。

“轻量”指本次界面使用的框架与绘制方式。已有识图、机器学习、CUDA 及独立 EXE 的运行库仍按原流程准备，这次没有重新构建独立 EXE。源码启动入口会使用新界面；此前打包的 EXE 需要重新构建才会包含本次更新。
