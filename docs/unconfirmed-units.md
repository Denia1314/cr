# 未确认目标与部署位置补偿（3.17.0 / V5）

V5 接入未确认视觉目标的显示与部署估计补偿；没有训练、晋级或替换识别模型，不代表兵种准确率或实战验收。

## 为什么超骑没框

跳跃/登场姿态可能被当前模型判成其他兵种且分数偏低；头顶等级标志不可见时也不能确定敌我。模型类别表含超骑不表示每个姿态都能识别。实时确定识别仍要求原 `runtime_confidence`（默认 0.7）和可关联的红/蓝等级标志。

试验切片模型在同一次推理中另保留默认至少 0.25 分的候选（`training.unconfirmed_unit_confidence`）。它们不进入确定的敌我单位列表，也不变成真实轨迹。高分确定目标优先分配等级标志，低分候选不能抢占；与确定目标重叠的候选移除。备用模型的原阈值保留。

YOLO 画面以黄色“未确认单位”框显示候选，确认数量和未确认数量单独列出；点击可查看类别候选、分数和未确认原因。类别候选可能错误，不按它直接配置确定单位属性。预览与推演使用各自同帧的实际候选，不借用旧帧当作新观测。

## 对推演的补偿

既有已确认我方出牌记录仍在 8 秒内提供逐渐降低存活血量的部署假设。新补偿只给这个已有假设修正位置：

- 机器人已确认出牌，且距确认不超过 3 秒；手动出牌、待确认或被拒绝动作不能创建补偿。
- 只处理召唤一个实体的牌；不把一个候选展开成整群部队。
- 候选至少 0.25 分，处于战场，有有效框；明确敌方候选或已被近期确定轨迹占用的候选排除。
- 候选必须在预计部署位置附近；普通单位限制 2.5 格，已具冲刺/跃击机制的单位放宽到 6.5 格，以覆盖跃击位移。
- 一条部署记录只匹配一个候选，候选也只能匹配一条部署记录。多个候选或多个部署记录争用时，保留原运动估计。

位置补偿仍是 `unconfirmed_ally_position_hypothesis`，同时保留 `unobserved_ally_survival_hypothesis`；没有新增确定轨迹、观测血量、敌方出牌或扣费。真实同牌我方观测优先并去重。方格战场继续把部署假设与当前确定观测分开，审计记录 `position_evidence=unconfirmed_visual_candidate`。

这能减少出牌后短暂漏识别对局势分析的影响；不能修正模型本身的类别误判。跳跃/登场识别准确率仍需覆盖这些姿态的真实样本、独立标注验证及实战验收。
