# 敌方身份持续锁定（3.21.0 / V8）

一次具有敌方阵营证据、真实身体框、已知可模拟兵种且 YOLO 置信度至少 0.80 的观测建立身份锚点。它是高置信视觉身份的跨帧延续，不代表模型不会认错；沿用现有模型、正常识别门槛及等级标志要求。

后续同一身体当前分数下降、类别跳动时，按预测位置、兵种移动速度与双向唯一最近关联保留原兵种。身体候选最低分数为 0.25，只能更新已有锁定，不能创建锁定；缺少阵营证据、我方身体、非法框及相邻目标关联不明确时均不绑定。模型当前类别和当前分数保留在审计中，不改成 80%。

两个近距离敌人分别建锁；无法区分交叉身体时暂停位置更新并标记身份待关联，避免强行合并、串身份或重复产生假想敌人。强识别建立锁定时可以沿用世界模型已有的同类或未知轨迹。

没有新身体证据时，最多保留最后一次观测后 3 秒；位置外推最多 0.75 秒。预览显示紫色暂估框。暂估行只进入预览，不作为新观测回灌世界模型，`last_seen` 不刷新，推演继续保留遮挡不确定性。可信零血量、新对局、时间倒退和超时会释放锁定。再次出现时重新识别。

预测决策与独立实时 YOLO 线程各自维护跟踪器，分别处理自己的原始同帧结果。重复同一帧不会刷新时间或重复确认；不改变识别器原始列表。V7 的我方出牌关联继续使用原逻辑。

画面区分“我方出牌绑定”和“敌方 YOLO 身份锁定”。敌方可见框显示锁定时分数与当前分数，漏检显示暂估。审计字段包括 `identity_source=enemy_yolo_tracking`、`identity_lock_id`、`identity_anchor_confidence`、`visual_card_id`、`visual_confidence` 和 `position_state`。

回归覆盖 80% 边界、低分错类、弱身体关联、短暂遮挡、3 秒超时、阵营隔离、交叉歧义、快兵移动、新对局、零血量、已有轨迹复用及实时线程同帧显示。代码与回归验证不等于真实对局身份准确率或完整实战验收。
