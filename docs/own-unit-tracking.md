# 出牌身份持续跟踪（3.19.0 / V7）

机器人确认下出卡牌后，将实际视觉身体与出牌记录关联，并持续保留兵种和实体编号。例如刚下的超骑跳跃时被模型判成冰人，已建立的绑定仍使用超骑身份和属性，同时保留模型当前类别与原始分数供检查。

V7 已接入预测策略（含其规则回退动作）的出牌确认、推演轨迹及独立实时 YOLO 画面。代码能力、运行权重、身份关联证据和真实对局验收分别记录；沿用现有识别权重。

## 建立绑定

- 只接收动作协议的 `confirmed` 记录。被拒绝、状态未知、一次点击或没有记录的手动出牌，都不能建立身份绑定。
- 结合下牌落点、下牌时间、部署延迟、移动速度和跃击范围寻找身体。出牌前已经存在的身体、明确敌方身体排除。
- 首次候选必须在确认后 3.5 秒内出现，最多在 6 秒内完成两张不同时间画面的连续关联；重复或倒序帧不能补足证据。
- 单体牌只占一个实体槽。同构群体按真实召唤数量分配独立槽，只有身体之间可唯一对应时才绑定；拥挤重叠的群体不会强行分配。混合召唤、分裂、变身及衍生单位暂不做身份继承。
- 多个身体或多次出牌争用同一目标时，保留未绑定状态。没有身体检测时，只有原来的部署假设，不能声称已经看见单位。

原确定识别门槛保持不变（默认 0.7），普通未确认候选仍默认至少 0.25。跟踪期间，同一次切片模型推理额外保留至少 0.1 的定位候选，标为 `tracking_only`，只供已确认出牌附近的关联检查。它们不会自行成为确定识别或普通黄色框。只有出牌验证、位置、两帧及唯一性检查通过后，才显示“出牌绑定”；身体分数不提高或伪造。

## 保持与结束

已绑定实体通过位置与运动连续性匹配，允许视觉类别改变。每个身体只属于一个实体，一条实体也只接受一个身体；追踪范围依速度、时间及跃击机制限制，跨场瞬移、明确敌方或歧义匹配不更新位置。

漏检时最多保留 3 秒，速度外推最多 0.75 秒，位置标为暂估；再出现且能唯一关联时沿用原编号。可信零血量、漏检超时或对局结束会结束绑定。实体槽不重复利用；已绑定出牌不会在丢失后重新生成一个假定存活单位。不会从没有画面证据的空白处宣称单位还活着。

## 画面和推演

实时预览和决策各自拥有跟踪器，只共享已确认出牌的副本，避免阻塞或修改另一线程的模型。各自的标记对应自己的实际源帧；下一局和离开战斗清空关联。

画面蓝框显示“我方 超级骑士 · 出牌绑定”；暂时看不到时用紫框并标“暂估”。统计分别显示普通识别、出牌绑定和暂估数量。点击框可检查稳定身份编号、出牌编号、身份来源、模型当前类别、身体分数和位置状态。

推演使用绑定的卡牌身份及原轨迹编号，包含短暂遮挡下的保守位置估计和未观测血量的不确定性。兵种身份来自出牌辅助关联，血量仍须独立观测；它不是 YOLO 分类准确度或实战胜率验收。

## 验证边界

测试覆盖模型类别切换、漏检重关联、重复帧、出牌确认延迟、旧身体、敌方、同构多实体、争用、异常位移、死亡和下一局清空，并验证推演不重复生成单位。保存的真实对局画面还通过当前实际权重回放，结果保存在本地报告目录，原始画面及模型不进入代码仓库。

本机回放沿用 `katacr-94d6cb863c80` 原权重和 2026-10-12 已确认超骑出牌记录：身体被原模型判为低分冰人，连续两张保存画面成功标为出牌绑定，并在推演中保持同一个世界轨迹编号及超骑属性。初次尚无身体或未满足两帧证据时，仍是部署假设。关联有歧义的模型框保留供查看，推演不把它另建为重复实体。

不能保证任何遮挡或混战后都找回同一实体。当前没有真实对局中长时间跟踪准确率、身份切换率或胜率验收；这些需要持续的人工核对与受控对局。
