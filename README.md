3.1.0 新增根据战场计算的动态落点：结合公主塔覆盖、敌军预计接触点、建筑拉扯和远程安全距离，比较出哪张牌、放在哪里，并评估塔伤与后续威胁。原有模式切换保持可用。

3.4.0 接入原始帧后台采集（只保留最新一帧）、相同牌槽识别缓存、GPU 启动预热及全格点 33 步伤害近似预测。发送前利用更新画面复核手牌、费用和威胁；动作确认只接收点击后开始采集的新帧。保留原策略和 PNG 截图回退。

3.3.1 按一格间距枚举当前模型允许部署的全部格点，取消每牌 24 个候选上限及相邻点过滤，法术覆盖全场格点。全部格点评分后按时间预算进行战斗精算；日志分别报告两种覆盖数，未精算完不宣称全局最优。

3.3.0 增加 GPU 批量落点评分：一格网格、每牌最多 24 个候选，搜索预算 160ms；优先保住公主塔，再比较塔伤和费用。GPU 仅承担落点排序，战斗事件模拟仍在 CPU，日志和推演状态提供实际调用数。兵种识别仍为假设时，结果不能视为精确最优解。

3.2.2 修复截图耗时超过 0.5 秒时所有方案被拦截的问题：默认总有效期调整为 2.5 秒，仍包含截图耗时并在点击前检查。没有场上敌军时交回原策略处理正常下牌，避免一直等待。

3.2.1 默认启用快速防守：完成四张手牌的空间比较后立即返回，计算预算 100ms；按预计塔伤选择费用最低的足够防守方案。可辨认的完整血条会更新单位血量，读数超过 0.6 秒失效；过期方案等待新画面。原策略切换保留。

3.2.0 逐张比较四张手牌的空间候选，默认每牌最多 12 个位置；记录各牌最佳落点、评分和预计塔伤。新增 132 条逐卡效果记录、分波/限目标/持续/线形/召唤/控制法术模拟，敌方半场出现单位时也生成到塔时间预测。尚有 13 个条目及部分主动技能/进化机制未完整映射，缺失卡不再阻断其他手牌的推演。

## 开始使用

1. 双击 `RoyalLab.exe`（首次构建运行 `build_exe.bat`；源码开发也可使用 `start_ui.bat`）。
2. 点击“连接并检测”；其他模拟器可用“自定义 ADB”填写端口。
3. 首次使用：进入离线人机页面，通过“工具 → 画面标定”保存离线标志。
4. 在“版本”下拉框选择原有策略、推演观察或 P1 预测推演；“旧规则”保留 V5–M3 配置。点击“离线训练”启动，“安全停止”结束。

主界面显示设备、离线校验、完成局数、实时画面和日志。画面标定、训练数据、精确标注、无标注自学、示范学习和双机同步统一放在“工具”菜单。

快捷键：`F5` 刷新画面，`Ctrl+Enter` 开始，`Esc` 安全停止。

“版本”下拉框的预测选项显示 **SL4 · 自动部署回退 / P1 推演**。原 M3-E 规则名称与保存键保留；停止后可以切回原有策略。下方模型状态每 3 秒自动刷新，显示最新训练或接收的模型版本及本次实际加载版本；点击可查看全部模型、验证结果和未加载原因。“工具 → 自主学习状态”查看审计、候选和失败原因。阶段名称表示已实现能力，权重版本与实际加载状态单独显示。程序仅运行已验证的离线人机对局。

知识库包含 132 张牌：指定网站的 121 张当前目录卡牌及 11 张兼容旧版的条目。已导入 1083 条等级记录，普通单位和已支持法术会读取详情数值；特殊机制仍单独审计。没有精确战场识别模型时，推演使用多种敌方威胁假设，日志会标明，不声称识别了具体敌牌。数据缺失或搜索无法完成时记录原因并回退原策略。

## 数据与训练

- **自动采集**：对局记录保存在 `runs/`，示范操作保存在 `demonstrations/`。
- **双机共享**：每台电脑首次运行 `setup_sync.bat`，重启控制台后自动同步；手动同步在“工具”菜单。
- **模型**：候选上传与实战启用分开；质量不合格的候选可同步，但不会自动晋级。
- **自主学习**：启动后的首个离线大厅和每 20 个可信完成局触发审计；同身份新增至少 100 局、500 条有效动作且通过覆盖要求后训练，间隔至少 2 小时。单轮最多 2 小时，当前复用一个已有学习配方。局间训练结束后重新识别画面再开局。
- **GPU**：NVIDIA 电脑通过启动脚本自动检查和准备 CUDA；手动修复运行 `setup_gpu.bat`，验证后重启控制台。
